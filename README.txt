EMBER MAP PROTOTYPE
===================

실행
- index.html을 브라우저에서 열면 됩니다.
- 외부 라이브러리/인터넷 연결이 필요하지 않습니다.

로고 파일
- assets/logos/ 폴더에 아래 규칙으로 1:1 이미지를 넣으면 상세 패널에 자동 표시됩니다.
- district-00.png
- district-01.png
- ...
- district-72.png

현재 구현된 기능
- 중앙 0구역 + 72개 방사형 구역 SVG 지도
- 오른쪽 아래 꼭짓점을 원 중심으로 사용
- 마우스/터치 드래그로 지도 회전
- hover 강조 및 툴팁
- 클릭 선택 / 정보 패널 표시 / 닫기
- 0구역 선택 시 무채색/검정 테마
- 구역 위치에 따라 북(주황)-동(적색)-남(청색)-서(녹색) 사이 색조 연속 보간
- 선택 시 배경 ambient gradient crossfade
- 리스트 보기 + 번호/이름 검색
- 범례 / 시스템 메뉴 플레이스홀더
- 반응형 레이아웃

데이터 교체
- index.html 안의 districtData 배열 생성부에서 name/description을 실제 설정으로 교체할 수 있습니다.
- 현재는 테스트를 위해 자동 생성된 플레이스홀더를 사용합니다.
